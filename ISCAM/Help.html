User Options

  • Grid size: Set the CA grid size. Minimum size is 10, maximum size is 1000. When the grid size is changed, all cell values are reset to 0.
  • Random seed: Set the random seed. If set to 0, a seed depending on the current clock time is taken. Otherwise the user provided seed value is used for initializing the CA grid.
  • S Dynamic: Set the S dynamic. Currently only one choice is available, viz. the ideal storage function.
  • R Dynamic: Set the R dynamic. Choose from a list of possible functions.
  • S control parameter: Set the control parameter (value of C) in the S dynamic.
  • R control parameter: Set the control parameter (value of C) in the R dynamic.
  • Diffusion: Set the diffusion rate. p=0.0 means no diffusion (only the cell's own current R value is used to determine its new R value), p=0.5 means a cell's new R value depends for 50% on its own current R value and for 50% on the average of the 8 neighboring cells. p=1.0 (full diffusion) means a cell's new R value is fully determined by the average of the 8 neighboring cells.
  • Diffusion noise: If on, at each iteration a uniform random value from [-r:r] is added to the given diffusion rate, where r is the range value provided. If off, the diffusion rate is kept constant over all iterations.
  • Zoom: Set the zoom level. This determines the size of the cells (in pixels) as drawn in the grid.
  • Show: Set after how many iterations the grid is re-drawn. Default value is 1 (every iteration).
  • Speed: Set how fast the CA is updated. A slower rate means a longer delay between updates.
  • Display: Specify what will be displayed:
    • S: Show the S values.
    • R: Show the R values.
    • S,R: Show the angle of the polar-coordinates representation of the (S,R) pair relative to the fixed point.
    • S vs R: Show the phase space of S vs. R values. The blue dot indicates the fixed point of the dynamics, while the red dot tracks the cell at position (0,0) (i.e., the top-left cell).
  • Grid lines: Show the CA grid lines (on) or not (off).
  • Color map: Choose between a monochrome or a rainbow color map.

Action Buttons

  • Init: Initialize the CA grid at random.
  • Step: Perform one update step of the CA.
  • Run: Continuously update the CA.
  • Stop: Stop the continuous CA updates.

  • JPG: Save the current CA grid (or phase space) as a JPG file.
  • Save: Save the current grid configuration and all parameter settings and user options to a file.
  • Load: Load a grid configuration and parameter values from a file.
  • Help: Show this help message.

  • Quit: Quit the ISCAM program.

CA Grid

The S and R values of individual cells in the CA grid can be modified manually by clicking on any cell. A small window will pop up, displaying the current values of the two variables. These values can be changed by clicking in the corresponding entry box and typing a new value. Remember to press the Enter key to apply the change (this is a Java "feature"...).
